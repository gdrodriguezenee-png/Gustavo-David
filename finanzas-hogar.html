Protege tus finanzas

Crea una contraseña. Tus datos se guardarán cifrados con AES-256 en este navegador y nadie podrá leerlos sin ella.

Importante: no hay forma de recuperar la contraseña. Si la olvidas, los datos se pierden. Anótala en un lugar seguro y exporta un respaldo desde la pestaña Datos.

Navegador no compatible

Este navegador no permite cifrado en archivos locales. Abre el archivo en Chrome, Edge o Firefox actualizados para poder usar la protección con contraseña.

Copia de seguridad

Tus datos se guardan cifrados en este navegador. Exporta un respaldo cada cierto tiempo o para pasarlo a otra computadora. El respaldo también va cifrado con tu contraseña actual.

Contraseña

Cambia tu contraseña. Los datos se vuelven a cifrar con la nueva; los respaldos exportados antes seguirán necesitando la contraseña anterior.

Zona de riesgo

Borra todos los movimientos, tarjetas, activos y configuración de este navegador. No se puede deshacer.
